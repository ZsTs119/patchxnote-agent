**日期：** 2026-08-28

本目录保存用户提供的四张原始参考图。它们用于理解产品外观、卖点、参数、佩戴方式和品牌信息，不直接作为官网最终上线素材。

| 文件 | 用途 | 原始来源 |

## 使用边界

- 不直接把浅蓝信息图贴进高级黑官网。
- 可以基于这些图生成或重绘符合官网风格的 hero 产品图、佩戴场景图、流程图和 OG 图。
- 生成素材要保留真实产品轮廓和 PatchX/PatchXNote 品牌信息，不夸大硬件能力。
- 官网示例图不得包含手机号、验证码、token、OAuth code、完整转写、原始录音或其他敏感信息。
- 上线前要压缩图片尺寸，并补充 alt 文案。

## 建议正式素材槽位

| 槽位 | 建议形式 |
| --- | --- |
| Hero product visual | 高级黑背景下的金属质感 PatchXNote 录音卡渲染图 |
| Setup preview | MCP 连接、授权、工具列表的抽象交互界面 |
| Wearing scene | 暗色摄影感佩戴场景，不直接复用浅蓝图 |
| Cloud platform visual | remote MCP URL + OAuth connector 的流程图 |
| OG image | 1200x630 的官网分享图 |

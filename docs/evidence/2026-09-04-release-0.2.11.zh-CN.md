## Go Test Notes

The local WSL default Go version is `go1.18.1`, which cannot build current dependencies requiring newer standard library APIs. Windows Go is `go1.24.6`, but direct testing from the WSL UNC path failed on `go.mod` file locking.

A Windows temporary copy passed this sequential package set with isolated test profile paths:

```sh
go test -p 1 ./cmd/patchxnote ./internal/api ./internal/auth ./internal/cache ./internal/cli ./internal/config ./internal/localfile ./internal/mcp ./internal/modelio ./internal/oauthflow ./internal/remotemcp ./internal/renderdoc ./internal/setup ./internal/version ./internal/webhook ./test/e2e
```

Known local limitation: `internal/keychain` was not accepted on Windows because `TestFileStorePutGetDelete` expects POSIX `0600` file mode, while Windows reports `-rw-rw-rw-`. Full Linux Go acceptance should run in CI/release workflow with the supported Go version.
